📊 Analyse & logique du programme

ANALYSE DU PROGRAMME EFFECTUÉ (S3-S21, janv-mai) & LOGIQUE DU NOUVEAU PLAN

1. STRUCTURE HEBDO TYPE DU PROGRAMME DE THOMAS

Run qualité (1 à 2/sem) : Seuil (blocs 6-12' @85% VMA / race pace), VMA (45/45, 400m, 1'30/1'30 @95-100%), maintiens d'allure et relances. Allures toujours calibrées sur tests (maintien d'allure S3, test VMA S8).

Aérobie / condi ergos (1/sem) : Volume Z2/Z3 à RPE 3-5 sur row/bike/ski, souvent avec burpees ou step-overs réguliers. Objectif : base cardio sans traumatisme musculaire.

Hard session Hyrox (1/sem) : Enchaînements stations + ergos à race pace, buy-in puis rounds sans récup. Simulation des transitions et de la pré-fatigue.

Renfo / force (1/sem) : Double drop sets (RDL, hip thrust), box front squats, backrack lunges, sleds en surcharge (80→140% race weight). Objectif : force des jambes et marge sur les poids de course.

Easy run (1/sem) : 40-45' Z1/Z2 + drills/accélérations. Récupération active, focus respiration.

Compromise / mixte (1/sem) : Courir à race pace sous fatigue (run + AMRAP stations). Spécifique Hyrox.

Repos (1-2/sem) : Dimanche fixe + 2e jour selon les blocs.

2. PÉRIODISATION OBSERVÉE

Blocs : Général (S3-S6) → affûtage court + course (S7) → bloc 2 avec re-test VMA (S8-S11) → taper + course (S12) → bloc final plus spécifique avec 2-3 runs qualité/sem (S14-S19) → affûtage → relay (S21).

Taper : Semaine de course : volume réduit dès J-4, dernière séance dure à J-5/J-4, activation courte J-2, repos J-1.

Principes clés : Tests réguliers pour recalibrer les allures ; pré-fatigue contrôlée ; unbroken imposé sur sleds ; régularité avant vitesse ; charge de course toujours travaillée en surcharge (110-140%).

3. ENSEIGNEMENTS DES RÉSULTATS (2024-2026)

Progression globale : Solo open : 1:33:25 (Nice 09/24) → 1:15:30 (Nice 02/26). Duo mixte : 1:16:34 → 1:10:09. Roxzone : 8:18 → 4:55. Allure run solo : 5:48 → 5:12/km ; duo : 4:52/km.

Points forts : Farmer carry (1:32-1:45 constant), Row régulier (~4:30), Ski stable (4:07-4:23).

Points faibles en solo : Wall balls : 5:01 à 7:55 en solo vs ~3:32-3:50 en duo → gros écart lié à la fatigue. Sled push très variable en pro (3:02 vs 4:55). Lunges solo 4:16-5:22.

Référence solo pro : Toulouse 03/26 : 1:23:07 (sled push 4:55 et WB 7:14 = ~5' perdues vs tes meilleurs splits). Bordeaux 11/25 : 1:26:56.

4. LOGIQUE DU NOUVEAU PROGRAMME (S32 → S44)

Contexte : 3 semaines d'arrêt volontaire → perte de cardio modérée. 5 séances/sem + EF optionnel le samedi (sauf semaines de course). Dimanche repos.

Phase 1 - Reprise (S32-S33) : Volume aérobie Z2, réintro technique des stations, renfo léger. Test de recalibrage des allures en S33. Interdiction de forcer : le cardio revient en 3-4 semaines, pas en 3 jours.

Phase 2 - Build (S34-S37) : Montée en charge : seuil + VMA + hard sessions. Les 3 duos (29/08, 05/09, 12/09) = entraînement : qualité placée en début de semaine, charge réduite jeu-ven, pas d'affûtage.

Phase 3 - Bloc spécifique solo pro (S38-S39) : Pic de charge : poids pro sur les stations, wall balls et sled push en priorité (tes 2 points faibles), 2 runs qualité/sem.

Phase 4 - Décharge + Genève (S40-S41) : S40 : volume -30%, intensité maintenue. S41 : affûtage → GENÈVE SOLO PRO ven 09/10.

Phase 5 - Récup + Nice (S42-S44) : Récup S42, dernière qualité orientée duo (allures plus rapides) S43, affûtage court → NICE DUO MIXTE jeu 29/10.

Anti-cramage : 3 vraies décharges (S35 partielle, S40, S42) + jamais plus de 2 semaines dures consécutives. Si fatigue anormale : remplacer la séance qualité par de l'EF, jamais l'inverse.
